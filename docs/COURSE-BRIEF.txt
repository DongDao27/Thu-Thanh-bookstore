Assignment Brief
Assignment Overview:
The project involves developing a PHP web application using the Laravel framework. The application will include features such as user authentication, user interface, RESTful API endpoints, and robust system logging and monitoring capabilities. 
Students are free to choose the functions to perform as long as they meet the assessment criteria and time allowed.
Objectives:
Implement version control to track changes and ensure an organized development workflow. Utilize Git for source code management, and establish a branching strategy for efficient collaboration.
Design a normalized database schema to support the application's functionality. Implement migrations to create and modify database tables. Seed the database with initial data for testing and development.
Design and implement a user-friendly interface using Laravel's Blade templating engine. Ensure responsiveness and a positive user experience across various devices.
Develop a RESTful API to provide programmatic access to the application's resources. Follow best practices for API design, including proper authentication, versioning, and documentation using Laravel's built-in tools.
Integrate logging mechanisms to capture and store relevant system events. Implement monitoring tools to track application performance, identify potential issues, and facilitate proactive maintenance.
Deliverables:
Source code repository with organized branches and commit history.
Database schema with migrations and seeders for initial data.
User interface implemented according to design specifications.
RESTful API with proper authentication and documentation.
System logging and monitoring integrated into the application.

UI/UX Peer Review & Evaluation Guide
The UI/UX of your project will be evaluated around three main criteria: usability, aesthetics, and user-friendliness. The guidelines for each are as follows:
Usability
Simplicity and Clarity: The interface should be easy to use and not create difficulties for users.
Information Clarity: Information and functions on the website should be easy to find and clearly understandable.
Navigability: Users should be able to move between pages and functions easily and logically.
System Feedback: The system should provide appropriate feedback when users perform actions (e.g., error notifications, success confirmations).
Multi-Device Support: The website should display well on various types of devices (desktop, tablet, mobile).
Aesthetics
Consistent Design: The interface should have a consistent design regarding colors, fonts, and styles.
Logical Layout: Elements on the page should be arranged in a logical manner to avoid a cluttered appearance.
Use of Colors and Images: Colors and images should be appropriate for the content and purpose of the website, avoiding being too glaring or mismatched.
User-Friendliness
Easy to Learn: New users should be able to quickly understand how to use the interface.
Time Efficiency: The interface should help users complete tasks quickly without requiring many steps.
Customization: The interface can be adjusted to suit the needs and habits of individual users (if applicable).
